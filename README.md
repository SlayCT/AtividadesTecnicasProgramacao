
**ATIVIDADES TECNICAS DE PROGRAMAÇÃO**

***01 - Programação Estruturada***

Instruções:
1. Implemente um programa que recebe repetidamente um número de 1 a 12, enquanto esse número for diferente de 0 (zero), e imprime o mês correspondente. Quando o número estiver fora do intervalo permitido, a mensagem "mês inválido" deverá ser exibida.

2. Faça um programa que receba a idade de 10 pessoas e que calcule e mostre a quantidade de pessoas com idade maior ou igual a 18 anos. Obrigatório o uso da estrutura for.

3. Faça um programa que mostre o menu de opções a seguir, receba a opção do usuário e os dados necessários para executar cada operação. Obrigatório o uso do switch/case.
Menu de opções:
  1. Somar dois números;
  2. Subtrair dois números;
  3. Multiplicar dois números;
  4. Dividir dois números;
  5. Raiz quadrada de um número.

------------------------------------------------------------------------------------------------------

***02 - ARRAY (VETOR / MATRIZ)***

Instruções:

1. Elabore um programa que preencha um array de 10 posições digitados pelo usuário(valores inteiros), ao final o programa deve subtrair 1 dos números impares e adicionar 1 aos números pares. Exibir em tela os novos valores do array.

2. Elabore um programa que preencha um array de 10 posições digitado pelo usuário(valores inteiros), calcule e mostre:
  a) A quantidade de números pares;
  b) Quais os números pares;
  c) A quantidade de números impares;
  d) Quais os números impares.

------------------------------------------------------------------------------------------------------


***03 - MATRIZ***

Instruções:

1- Desenvolva um programa em Java que represente uma lista de contados utilizando um Switch Case e uma estrutura de Repetição While com as seguintes Opções: 
  a. Adicionar um contato em uma matriz 5x3: Nome, E-mail WhatsApp
  b. Remover um contato deixando texto "DISPONÍVEL" nas colunas
  c. Exibir um contato passando o índice
  d. Sair

2- Escreva um programa em Java que receba via console os dados de uma matriz 3x3 de números inteiros. O programa deverá analisar os dados inseridos e exibir: a matriz original na tela, a média aritmética de todos os valores e a quantidade de números pares que foram digitados pelo usuário.

3 - Desenvolva um programa em Java que leia uma matriz 3x3 de números inteiros. O programa deve obrigar o usuário a digitar apenas números positivos (se digitar um número negativo, use uma estrutura de repetição para exibir uma mensagem de erro e pedir o número novamente até que ele seja válido). Após preencher a matriz corretamente, exiba um menu de opções (usando switch-case) para o usuário escolher entre:
  1. Somar apenas as linhas pares (0 e 2)
  2. Somar apenas as colunas ímpares (1)
  3. Sair do programa
